## 游戏简介

《校园摸金》是一款俯视角 2D 搜刮撤离类小游戏。玩家扮演一名潜入校园的"摸金人"，需要在限时内尽可能多地搜刮物资箱中的值钱货，并赶在倒计时结束前抵达撤离点。

游戏强调**风险与收益的权衡**：贪婪地多搜一件可能错失撤离时机，一旦超时则全部物资清零。简洁的色块画面下隐藏着经典的"搜—存—撤"紧张循环。

## 核心玩法

| 环节 | 说明 |
| --- | --- |
| 🔍 **搜刮** | 靠近橙色物资箱，按 `E` 搜索，随机获得一件带品质与价值的物资 |
| 🎒 **管理** | 实时统计背包件数与总价值，权衡是否继续搜刮 |
| 🏃 **撤离** | 跑到右下角蓝色撤离点，按 `E` 结算，成功撤离才能保留物资 |
| ⏱️ **限时** | 180 秒倒计时，超时未撤离则**丢失全部物资** |

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / `↑` `←` `↓` `→` | 控制角色四方向移动 |
| `E` | 靠近物资箱时搜索 / 靠近撤离点时撤离 |

> 提示：每个物资箱只能搜索一次，重复按 `E` 会提示"箱子已经搜过了"。

## 物资与品质

物资按稀有度分为 6 个品质，价值越高越难获得：

| 品质 | 物资 | 价值 | 出现概率 |
| --- | --- | --- | --- |
| ⚪ 白 | 旧电池 | 50 | 较高 |
| ⚪ 白 | 绷带 | 120 | 较高 |
| 🟢 绿 | 手电 | 200 | 中 |
| 🟢 绿 | 弹匣 | 350 | 中 |
| 🔵 蓝 | 军用电台 | 800 | 较低 |
| 🟣 紫 | 显卡 | 1500 | 低 |
| 🟡 金 | 黑匣子 | 3000 | 很低 |
| 🔴 红 | 曼德尔超算 | 5000 | 极低 |

掉落按权重随机：白装约 45%、绿装约 30%、蓝装约 15%、紫装约 7%、金 / 红装合计约 5%。

## 游戏规则

1. 地图内随机生成 **8 个物资箱**，位置避开撤离点，避免刷在撤离区。
2. 搜索物资后，背包件数与总价值实时累加并显示在左上角 HUD。
3. 撤离点位于地图右下角（蓝色色块），靠近后按 `E` 触发结算。
4. **撤离成功**：保留全部已搜物资并展示总价值。
5. **超时失败**：背包清空、价值归零，当局成绩作废。

## 快速开始

无需安装依赖，本地直接打开即可：

```bash
# 1. 克隆仓库
git clone https://github.com/daya2014/mijin.git
cd mijin

# 2. 用任意静态服务器打开（推荐，避免本地文件跨域问题）
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000

# 或直接双击 index.html 用浏览器打开
```

## 项目结构

```text
mijin/
├── index.html    # 入口页面，加载 Phaser 与游戏脚本
├── game.js       # 游戏主逻辑（场景、玩家、物资、撤离、倒计时）
└── README.md     # 项目说明文档
```

> ⚠️ `index.html` 与 `game.js` 必须位于**仓库根目录**，GitHub Pages 才能在 `/mijin/` 路径下正确加载游戏。

## 技术栈

- **Phaser 3.60.0** — HTML5 2D 游戏引擎（通过 CDN 引入）
- **原生 JavaScript (ES6)** — 场景与玩法逻辑
- **Canvas / WebGL** — 渲染后端（`Phaser.AUTO` 自动选择）
- **GitHub Pages** — 静态托管与自动部署

游戏当前使用程序生成的色块作为占位贴图（`generateTexture`），无需任何美术资源即可运行。
